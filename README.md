# kasp-test-task-2

## Описание

Проект `kasp-test-task-2` представляет собой тестовое задание для компании "Лаборатория Касперского".  
Текстовое поле с подсветкой вводимого текста.  

Подсветка:  
- операторы OR, AND, NOT
- слова в кавычках "";
- слова в кавычках ““;
- слова с тегами 'ID', 'TI', 'AB', 'URL', 'DOM' и другими. (можно посмотреть в коде)

Экранирование кавычек, которые находятся внутри других кавычек
